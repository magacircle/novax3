# NovaX™ Hub Prototype V1

Prototype objective: validate the free Builder Journey experience using the existing V41 functional Quiz/Profile/Invite/Reward baseline.

Flow: Landing → Identity → Quiz → Builder Profile → NovaX Hub → Journey → Invites → Founder Rewards → Founders Gate → Path Discovery.

Theme: automatic initial theme follows OS/browser preference via prefers-color-scheme; visible Builder control is Light/Dark only. Manual choice persists in localStorage as novax_theme.

Brand: Signature #5 reference crops from the supplied identity board are used in this prototype as working visual source assets. Final production should replace these reference crops with exact source logo assets when available.

Production integrations intentionally not included: real Google/Apple auth, Stripe, GrowSurf settlement, Mautic, Relaticle, production PostgreSQL, First Circle, Circle matching, Builder Connection, Vanguard application, funding infrastructure, AI Workforce runtime.
